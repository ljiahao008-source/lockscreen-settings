锁屏设置（桌面版 v3.0）
=====================================
单文件 C# 程序：直接调用系统 powercfg 与注册表，
无后台进程、无端口、无浏览器依赖。即用即退。

【用法】
双击「锁屏设置.exe」（或桌面 / 开始菜单里的「锁屏设置」快捷方式）→
直接打开图形界面窗口。关窗即退出，不留任何进程。

目录结构（根目录只留一个程序，其余都在子目录）：
  锁屏设置.exe       唯一程序（图形界面 + 命令行都是它，约 0.2MB）
  data\                  导出配置等数据（自动生成，可随意删）
  工具与文档\            使用说明、build.bat（重新打包脚本）
  src\ backup\           源码与旧版备份（不需要可整体删除）

默认以管理员模式运行：双击后会弹出一次 UAC 授权提示
（「用户账户控制 → 是否允许此应用更改你的设备」）。
- 点「是」：以管理员权限运行，屏保 / 休眠 / 恢复系统默认等操作全部可用；
- 点「否」：降级为普通权限继续运行，日常电源设置不受影响
  （仅开启休眠、恢复系统默认等少数操作需要管理员）。
命令行模式（--status / --export 等）不需要管理员，不会弹 UAC。
若不想自动提权，可设环境变量 LOCKSCREEN_NO_ELEVATE=1 后启动。

【能设什么】（图形界面三个标签页）
- 🔒 锁屏后黑屏：锁屏壁纸出现后多久自动关屏
- 🖥 关闭显示器：闲置多久关屏
- 😴 睡眠 / 💤 休眠：闲置多久进入
- 🖼 屏幕保护程序：开关 + 等待时间
- 📱 动态锁：离开自动锁屏（开关 / 信任设备 / 蓝牙密钥健康度检查）
全部可设「永不」。

【图形界面特性】
- 「接通电源」与「使用电池」分开设置（笔记本才显示电池行）
- 自定义任意时间：每行输入分钟数，点「应用」或「↕ 同步两项」
- 一键全部永不、恢复系统默认、刷新
- 状态栏：当前电源计划名 / 休眠功能是否开启
- 配置导出 / 导入：换电脑或重装后一键还原（文件菜单）

【命令行模式】（设完即退，适合写进脚本 / 批处理）
  锁屏设置.exe display=10min
  锁屏设置.exe ac:sleep=30min dc:sleep=20min
  锁屏设置.exe lock=never saver=off
  锁屏设置.exe --status         打印当前所有设置
  锁屏设置.exe --export         把当前设置存成「锁屏设置.json」（data\ 下）
  锁屏设置.exe --import         从「锁屏设置.json」还原（换电脑用）
  锁屏设置.exe --show           只查看配置文件内容，不应用
  锁屏设置.exe --dynlock       查看动态锁状态
  锁屏设置.exe --dynlock=on    开启动态锁

时间值：never(永不) / 30s / 10min / 2h / 600（纯数字=秒）
模式前缀：ac: 仅接通电源，dc: 仅使用电池，不写 = 两项都改
一次可写多项：锁屏设置.exe display=10min ac:sleep=30min saver=off

【换电脑 / 重装系统时迁移设置】（不需要管理员权限）
电源计划设置是写在系统里的，不会跟着 exe 走。要在新电脑恢复：
  1. 旧电脑：打开图形界面 → 文件 → 导出配置
     → 存成「锁屏设置.json」（默认存 data\）
  2. 把整个文件夹拷到新电脑（或只拷 exe + 锁屏设置.json）
  3. 新电脑：打开图形界面 → 文件 → 导入配置
     → 全部设置（4 项时间 + 屏保 + 动态锁开关）一次性还原
命令行等价操作：--export / --import / --show

【便携性】
整个文件夹拷到 U 盘 / 其他 Windows 电脑，双击「锁屏设置.exe」即可用。
- 单文件程序，无安装、不写注册表（除设置项本身）、无后台进程
- 需要 .NET 8 桌面运行时（Windows 10/11 一般已内置或自动安装；
  缺失时 Windows 会提示下载）
- 要求：64 位 Windows 10 / 11（Server 2016+）。
  （Win 7 / 32 位系统不支持）

【休眠】
只有已开启休眠的系统（hiberfil.sys 存在）才能设置休眠时间。
未开启时：
  - 图形界面会给出提示
  - 以管理员身份运行 powercfg /h on 开启（本程序默认管理员模式，可在命令行跑）

【修改源码后重新打包】
src\gui\ 下是 C# 源码。改后跑 工具与文档\build.bat：
  - 需 .NET 8 SDK
  - 产物：根目录「锁屏设置.exe」（单文件，约 0.2MB）
